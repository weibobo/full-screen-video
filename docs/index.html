Video Fullscreen Helper / 视频全屏助手

Chrome extension — force the video in the current tab to fill the window

English 中文（简体） GitHub

Effective date: 2026-09-21

Short answer: this extension does not collect, transmit, share, or sell any personal data. All processing happens locally in your browser, on the page where you invoke it.

English

What the extension does

Video Fullscreen Helper lets you force the video playing in the current tab to fill the browser window (web fullscreen) or the whole screen (browser fullscreen). It works by applying style changes to the page — nothing more.

Data we collect

None. The extension does not collect, store, transmit, share, or sell any personal information or user data. Specifically, it does not collect:

  • personally identifiable information of any kind
  • browsing history, URLs, or page content
  • video URLs, playback activity, or keystrokes
  • analytics, telemetry, or crash reports

It contains no cookies, no trackers, no third-party scripts, and no remote code. The full source code is public and auditable on GitHub.

Local storage

The extension stores exactly two UI preferences (whether to show native video controls, and whether to stretch the video) using chrome.storage.local. This data stays on your device, is never synced or uploaded, and can be removed at any time by removing the extension.

Permissions

  • Host access (http/https) — the content script must be able to run on any site where you play a video. It only locates the video/player element on the page where you invoke the extension and applies fullscreen styles.
  • activeTab / scripting — used when you click the toolbar button or press the shortcut, to run the fullscreen command on the current tab.
  • storage — stores the two UI preferences described above.

中文（简体）

这个扩展做什么

视频全屏助手让你把当前标签页中播放的视频强制铺满浏览器窗口（网页全屏）或整个屏幕（整个全屏）。它通过向页面应用样式变更来工作——仅此而已。

我们收集的数据

无。本扩展不收集、存储、传输、共享或出售任何个人信息或用户数据。具体来说，不会收集：

  • 任何形式的可识别个人身份的信息
  • 浏览历史、网址或页面内容
  • 视频地址、播放行为或按键
  • 统计分析、遥测或崩溃报告

它不包含 Cookie、跟踪器、第三方脚本和远程代码。完整源代码在 GitHub 上公开，可自行审计。

本地存储

扩展仅使用 chrome.storage.local 存储两项界面偏好（是否显示原生控制条、是否拉伸铺满）。该数据只保存在你的设备上，绝不会同步或上传；移除扩展即可随时删除。

权限说明

  • 主机权限（http/https）——内容脚本需要能够在任意播放视频的网站上运行。它只在你主动调用扩展的页面上定位视频/播放器元素并应用全屏样式。
  • activeTab / scripting——在你点击工具栏按钮或按下快捷键时使用，用于在当前标签页上执行全屏指令。
  • storage——存储上述两项界面偏好。
