# Chrome Web Store 商品信息 — 简体中文

在开发者控制台的商品语言列表里添加"中文（简体）"后，从本文件逐项粘贴。

## 商品信息

- **名称**: 视频全屏助手
- **简短描述** (≤132 字符):

```
把当前标签页的视频强制铺满浏览器窗口——当站点自带的网页全屏失效时依然有效。
```

- **类别**: 效率工具
- **语言**: 中文（简体）（英文版默认语言，文案见 listing.en.md）

### 详细描述

```
很多视频站点自带的"网页全屏"按钮是坏的，只能用真全屏。视频全屏助手直接改写页面样式，把当前标签页里的视频强制铺满窗口。

两种模式

• 网页全屏 —— 视频占满整个浏览器窗口，浏览器保持窗口状态（任务栏和其他窗口仍然可见）
• 整个全屏 —— 浏览器进入全屏模式，视频占满整个屏幕

为什么站点自己的按钮失效时它依然有效

• 直接给播放器容器、<video> 元素或内嵌 iframe 强制注入内联样式，不依赖站点自身的 CSS
• 防遮挡：自动检测并处理会盖住视频的站点顶栏、侧栏、悬浮挂件和弹窗
• 自适应站点变化：改写布局、更换视频元素（如切换清晰度）、播放中途弹出新的浮层，都会自动重新处理
• 进入前对所有改动做快照，退出时完整还原，不留痕迹

使用方法

• 点击工具栏图标选择模式，动作成功后弹窗自动关闭
• 页面内按 Esc 退出（整个全屏会把浏览器窗口一并还原为之前的状态）
• 可选：显示浏览器原生视频控制条；或把视频拉伸铺满窗口
• 快捷键默认不绑定，可在 chrome://extensions/shortcuts 自行设置

隐私

本扩展不收集、不传输、不出售任何数据。所有处理都只在你本地浏览器中、在你主动调用的页面上进行。无统计、无远程代码、无外部请求。
```

## 隐私权设置

### 单一用途

```
让用户通过弹窗按钮或键盘快捷键，把当前标签页中正在播放的视频铺满浏览器窗口或整个屏幕。
```

### 权限用途说明

- **主机权限（http/https，所有网站）**:

```
视频网站是任意的，因此需要内容脚本能够在任意 http(s) 页面上运行。脚本只在用户主动调用扩展的页面上定位 <video>/播放器元素并应用全屏样式，不读取页面内容、不收集数据、不与任何服务器通信。
```

- **activeTab**:

```
在用户点击扩展按钮或使用快捷键时获得对当前标签页的一次性访问权限，用于向该页面下发全屏指令。
```

- **scripting**:

```
仅作为兜底手段，在页面尚未注入内容脚本时（如页面先于扩展加载）注入本地打包的脚本，使全屏指令可以执行。只执行本地打包的代码，从不执行远程代码。
```

- **storage**:

```
在本地设备上保存用户的两个界面偏好（是否显示原生控制条、是否拉伸铺满）。
```

## 提交流程备忘

1. [开发者控制台](https://chrome.google.com/webstore/devconsole) 注册（Google 账号开两步验证 + 一次性 $5）
2. 新建商品 → 上传 `dist/full-screen-video-v1.0.0.zip`（`node tools/pack.js` 生成）
3. Store listing 标签页：粘贴本文件与 listing.en.md 的名称/描述，选类别，传截图
4. Privacy practices 标签页：粘贴单一用途与权限说明，勾"不收集数据"
5. Distribution：可见性选 Public（或先 Unlisted 自用）→ 提交审核
6. 宽权限（所有网站）审核较慢，一般几天到数周
